# 日本代购二次元：IP 词典与产品分类（网络附录）

硕士学位论文《日本动漫衍生品跨境消费的世代差与持续购买研究——基于问卷与交易数据的分析》的网络附录。论文纸质附录只保留问卷、变量编码、归并规则、双编码检验、分类总览与清洗流程；**规范 IP 全表**和**三级分类全表**放在本仓库，供核对。

本仓库**不含**用户标识、订单、地址、问卷作答或任何可定位到个人的数据。

## 文件

| 文件 | 内容 |
|:-----|:-----|
| [`data/ip_dict.csv`](data/ip_dict.csv) | 规范 IP 词典，732 条。列：规范中文名、规范日文名、IP来源、是否纳入日本主分析、匹配别名 |
| [`data/taxonomy.csv`](data/taxonomy.csv) | 《日本代购二次元产品分类体系》确认稿，三级 103 条 |

编码为 UTF-8（带 BOM），可用 Excel 直接打开。

## 怎么读 IP 表

- **是否纳入日本主分析 = 是**：598 条。进入正文日本主 IP 的集中度与跨年延续。
- **是否纳入日本主分析 = 否**：134 条。标题可以识别（如原神、迪士尼），不进日本主表。
- 同中文名、日文名不同的，各占一行。
- 匹配别名用竖线 `|` 分隔。别名用于标题匹配，正文表格用规范中文名。

论文正文规模层按 **643** 个规范 IP 报告词典规模，日本主分析 **105,315** 条、**507** 个规范 IP、**7,676** 名用户。人数与条数以正文为准。本表供核对某作品是否在词典里、是否进入日本主分析，不据此重算正文分母。

## 怎么读分类表

一级 4 类、二级 26 项、三级 103 项。规模层每条商品落到一个三级。

标题同时可归入更细和更粗两档时，优先更细的三级：写明「明信片」走明信片，只写「特典」且没有更细词才走特典。特典 CD 仍走音乐 CD。其他-非二次元不计入二次元主分析，也不进入日本主 IP。

使用本表时请同时引用学位论文。核对某条规范名或三级类目，以本仓库 CSV 为准。
